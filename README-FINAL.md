## 🚀 **Quick Start**

```bash
cd frontend
npm install --legacy-peer-deps
npm start
# Then press 'i' for iOS simulator
```

### If You Get Dependency Errors:

```bash
# Use legacy peer deps (recommended)
npm install --legacy-peer-deps

# Or install with force
npm install --force
```

## 🔧 **Troubleshooting**

```bash

```


```bash

```
